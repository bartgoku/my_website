# Logo's voor Website

Voor de beste prestaties en betrouwbaarheid kun je hier logo's toevoegen voor:

## Bedrijven:
- `ilionx.png` - ilionx logo
- `eo.png` - Evangelische Omroep logo  
- `dictu.png` - DICTU logo
- `rtl.png` - RTL Nederland logo

## Universiteiten:
- `rug.png` - Rijksuniversiteit Groningen logo
- `hva.png` - Hogeschool van Amsterdam logo
- `ballstate.png` - Ball State University logo

## Aanbevolen formaat:
- PNG of SVG bestanden
- Minimaal 64x64 pixels
- Transparante achtergrond waar mogelijk
- Maximaal 10KB per bestand

## Bronnen voor logo's:
- Officiële websites van de organisaties
- Wikimedia Commons (voor publieke logo's)
- LinkedIn bedrijfspagina's
- University brand guidelines
